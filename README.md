# Vilaca Tap

## How do I install these formulae?

`brew install vilaca/tap/<formula>`

Or `brew tap vilaca/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "vilaca/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
